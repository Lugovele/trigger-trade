# Post-release validation obligations

These are continuing validation obligations, not release blockers.

1. When data after 2026-09-30 exists, apply the frozen canonical protocol unchanged to a separately frozen later period.
2. Use a new outcome-blind panel on later data.
3. Prefer context-isolated independent reviewers.
4. Report results; do not tune the canonical version.
5. Monitor endpoint-only veto rate, p0/source-step precision dependence, RMS48 regime-transition behavior, volatility-quintile directional gradient, and tick/source-representation changes.
6. Re-run conformance for every new calculation/runtime version.
7. Any semantic change requires a new protocol version.
